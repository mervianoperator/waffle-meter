# waffle-meter
[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.23453371.svg)](https://doi.org/10.5281/zenodo.23453371)

Waffle Meter (WM) v1.2 is a deterministic, privacy-first Python tool for multilingual AI text detection &⁷ verbosity analysis. Operating locally in Pydroid3/terminal, it combines letter-sum indexing ($a=1 \dots z=26$), Fibonacci deltas, FKGL/Gunning Fog readability, and filler density into a normalized Composite Waffle Index (CWI 0–100).
